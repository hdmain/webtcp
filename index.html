About this project

rawuploader (tcpraw) is a tool for sending and receiving files over TCP using 6-digit access codes. The server and client are written in Go (Golang) — the backend is fast, easy to deploy, and has no external dependencies. Files are encrypted on the client side (AES-256-GCM), and the server stores only encrypted data; no sign-up required, just the code.
